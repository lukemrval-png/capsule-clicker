# Capsule Clicker (Android, без root)

Аналог твоего ПК-кликера, но приложением на планшете/телефоне. Ищет на экране
запомненную «капсулу» (по картинке) и тапает по ней. Работает **без root**:
тапы идут через AccessibilityService, экран читается через MediaProjection.

Проверено под Android 14 (Redmi Pad Pro), minSdk 26 (Android 8+).

---

## Как это работает

- **ScreenCaptureService** — читает кадры экрана (MediaProjection + ImageReader).
- **Matcher** — ищет шаблон по grayscale c даунскейлом (нормированная корреляция, без OpenCV).
- **ClickAccessibilityService** — делает тап жестом в найденной точке.
- **OverlayController** — плавающая панель поверх игры: «Цель», «Старт/Стоп», порог.

## Сборка APK

### Вариант A — без Android Studio, через GitHub Actions (проще)

1. Создай репозиторий на GitHub и загрузи в него содержимое папки `android_capsule_clicker`.
2. Открой вкладку **Actions** — workflow «Build APK» запустится сам (или нажми
   *Run workflow*).
3. Когда сборка станет зелёной: **Actions → последний запуск → Artifacts →
   `capsule-clicker-debug-apk`**. Скачай, внутри `app-debug.apk`.
4. Перекинь APK на планшет и установи (нужно разрешить «Установку из неизвестных
   источников»).

### Вариант B — Android Studio

1. `File → Open` и выбери папку `android_capsule_clicker`.
2. Дай студии синхронизировать Gradle (сама скачает нужный Gradle/SDK; при
   запросе создать Gradle Wrapper — согласись).
3. `Build → Build APK(s)` или запусти на подключённом планшете (кнопка Run).

> Wrapper (`gradlew`) в проект намеренно не положен. Android Studio создаст его
> сам, а CI использует Gradle из `setup-gradle`.

## Установка и настройка на планшете

1. Установи APK, открой приложение.
2. **Шаг 1 «Включить службу тапов»** → в списке спец.возможностей включи
   «Capsule Clicker» (система предупредит про доступ к экрану — это нужно для тапов).
3. **Шаг 2 «Разрешить поверх окон»** → включи разрешение.
4. **Шаг 3 «Запустить захват + панель»** → подтверди захват экрана.
   Приложение свернётся, поверх появится маленькая панель.
5. Открой игру. На панели:
   - **Цель** — тапни по капсуле (она должна быть видна). Приложение запомнит её
     вид и зону вокруг.
   - **Старт** — начнёт искать и кликать. **Стоп** — остановит.
   - **− / +** — порог сходства (ниже = срабатывает чаще, но больше ложных кликов).
6. Панель перетаскивается за строку заголовка. «Закрыть» — выключить всё.

## Настройка чувствительности

- Порог по умолчанию **0.65**. Кликает по лишнему → подними (+). Не видит капсулу
  → опусти (−).
- Скорость/зону можно поменять в `ClickerState.kt`:
  - `searchScale` (0.25) — меньше = быстрее, но грубее.
  - `cooldownMs` (500) — пауза между кликами.
  - зона поиска задаётся автоматически рамкой ±400 px вокруг цели (см.
    `OverlayController.captureTemplateAt`).

## Ограничения (честно)

- Ориентация экрана фиксируется в момент запуска захвата. Сменишь портрет/ландшафт
  во время работы — перезапусти захват (Стоп → шаг 3).
- Игры с защитой от ботов / переворачиванием могут это детектить — риск бана на
  твоей совести (нарушение правил игры).
- Это MVP: одна цель за раз, поиск по яркости (без цветовой проверки). При желании
  можно добавить несколько шаблонов и цветовую ступень, как в ПК-версии.
- Код не компилировался в среде, где создавался. Если первая сборка выдаст мелкую
  ошибку — пришли текст, поправлю.
